## What this evidence does and does not establish

This evidence establishes that the listed GitHub Release assets can be identified by their checksums and that the package artifacts have GitHub build provenance.

It does not prove a hosted production deployment, does not publish the package to PyPI, and does not make any host integration Production-tested. Cited Vault Recall remains local-first, read-only, and offline by default; its synthetic Hermes integration evidence is deliberately narrower than production evidence.

For the process required before any future release, see the [release and provenance policy](../release-provenance.md). For current publication and deployment gates, see the [release readiness matrix](../release-readiness.md).
